# Установка и диагностика

Для обычной установки найдите Tolmach в каталоге Gale или r2modman и установите в нужный профиль Valheim. Менеджер установит зависимости BepInExPack_Valheim и JsonDotNET. Tolmach устанавливается у игрока; серверу он не требуется. Переводимые моды устанавливаются отдельно. Затем запустите игру через этот профиль, выберите русский язык и перезапустите её после смены языка. Откройте окно или подсказку, перечисленные в [покрытии](COVERAGE.md): перевод применяется автоматически.

[Карточка мода и настройки](../package/README.md) · [Что переведено](COVERAGE.md) · [Сообщить об ошибке](https://github.com/Muratovnik/tolmach/issues/new)

## Установка из архива

Этот способ нужен для ZIP из GitHub, например при проверке новой сборки. Скачайте `Muratovnik-Tolmach-<версия>.zip` из [нужного релиза](https://github.com/Muratovnik/tolmach/releases), а не автоматически сформированный GitHub архив исходников `Source code`.

### Импорт в менеджер

В Gale откройте нужный профиль, выберите «Импорт» → «…локальный мод» и укажите ZIP. Также можно перетащить ZIP в окно Gale. После импорта проверьте, что в профиле включены Tolmach и его зависимости.

В r2modman предусмотрен путь Settings → Import local mod. Импорт Tolmach этим способом не подтверждён отдельной проверкой проекта; для обычной установки используйте каталог Thunderstore. При сообщении об ошибке импорта приложите версию менеджера и текст ошибки.

Перед обновлением закройте игру. Не оставляйте две копии Tolmach в разных подпапках `BepInEx/plugins`: после запуска должна загружаться одна DLL плагина. Для экспериментов с новой сборкой удобнее использовать копию профиля.

### Копирование файлов вручную

Сначала установите BepInExPack_Valheim и JsonDotNET по их инструкциям. Закройте игру, создайте папку `BepInEx/plugins/Tolmach` в выбранном профиле и скопируйте в неё **содержимое** папки `plugins` из ZIP.

Должна получиться такая структура:

```text
BepInEx/
  plugins/
    Tolmach/
      Tolmach.dll
      catalog/
        tolmach-AdventureBackpacks.json
        ...
```

`catalog` должен лежать рядом с `Tolmach.dll`. Не переименовывайте файлы каталогов и не кладите JSON прямо в корень папки плагинов. Затем запустите игру обычным для этого профиля способом, выберите русский язык и перезапустите игру после его смены.

### Проверка хеша ZIP

Это дополнительная проверка скачанного файла, не обязательный шаг установки через менеджер. Скачайте `SHA256SUMS` **из того же релиза**, что и ZIP.

В PowerShell откройте папку загрузки и укажите версию скачанного пакета:

```powershell
$version = '0.11.0' # замените на версию скачанного релиза
(Get-FileHash ".\Muratovnik-Tolmach-$version.zip" -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content .\SHA256SUMS
```

Сравните хеш с записью именно этого ZIP. В Linux в папке с файлами можно выполнить `sha256sum -c SHA256SUMS`. Совпадение подтверждает соответствие файла опубликованной контрольной сумме, но не игровую совместимость.

Исторические хеши из `docs/evidence` могут описывать предварительные локальные сборки. Для скачанного релиза используйте его собственный `SHA256SUMS`, не хеш из старого протокола.

## Диагностика

Сначала проверьте профиль, включение Tolmach и нужного мода, русский язык и перезапуск игры. Затем найдите интересующий экран в [покрытии](COVERAGE.md): наличие мода в списке не означает перевод всех его настроек и служебных окон.

### Где находятся файлы

В папке профиля:

| Файл | Назначение |
|---|---|
| `BepInEx/config/muratovnik.tolmach.cfg` | Настройки Tolmach; редактируются при закрытой игре. |
| `BepInEx/config/Tolmach.runtime.txt` | Краткий отчёт о текущем или последнем запуске плагина. |
| `BepInEx/LogOutput.log` | Журнал BepInEx: загрузка DLL, ошибки запуска и подробности исключений. |

Перед отправкой полного журнала проверьте его содержимое: журнал других модов может включать локальные пути или пользовательские данные. Для замечания о формулировке обычно достаточно скриншота и версии мода.

### Как читать отчёт

Проверьте время `Started UTC` и обновления `UTC`, а также `Session`. Этот же идентификатор Tolmach пишет в журнал при запуске. Если файл старый, он не описывает текущий сеанс.

| Поле | Что означает |
|---|---|
| `Status: Initializing` | Плагин начал запуск, но завершение ещё не записано. После сбоя проверьте журнал. |
| `Status: Active` | Инициализация плагина завершилась. Состояние отдельных адаптеров нужно смотреть ниже. |
| `Status: Disabled` | Tolmach отключён параметром `[General] Enabled = false`. |
| `Status: MissingCatalog` | Рядом с DLL нет папки `catalog`; переустановите полный пакет. |
| `Status: Failed` | Ошибка инициализации; подробности находятся в журнале BepInEx. |
| `Status: Stopped` | Плагин выгружен, например при закрытии игры. Само по себе это не ошибка. |
| `Russian selected: True` | Плагин определил русский язык. |
| `Russian active: True` | Совместимый с прежним форматом флаг: плагин инициализирован и выбран русский язык. Он не подтверждает перевод всех экранов. |

Ниже идут найденные модули, пропуски и предупреждения. Несовпадение версии отличается от отсутствия мода. `uiAllowed=False` означает, что адресные переводы интерфейса для этого модуля не разрешены. Предупреждения об отсутствующих методах и литералах относятся к известным целям адаптера: новые неизвестные строки они не перечисляют.

При отключении Tolmach **в менеджере**, удалении DLL или сбое до загрузки плагин не выполняется и не может обновить отчёт. Старый файл на диске не является признаком работающего перевода. В старых версиях формата может не быть `Session` и `Status`; ориентируйтесь на дату файла и запись загрузки Tolmach в текущем журнале, а не только на `Russian active`.

### Сообщение об ошибке

[Создайте обращение](https://github.com/Muratovnik/tolmach/issues/new), укажите мод и его версию, экран или действие и приложите скриншот либо полную строку. Полезно указать язык при запуске и менялся ли он без перезапуска.

Для проблемы установки или работы адаптера дополнительно приложите свежий отчёт и соответствующий фрагмент журнала. Отчёт не нужен для объяснения, почему русская фраза звучит неудачно.

## Удаление

Закройте игру и удалите Tolmach через менеджер. При ручной установке удалите только папку, куда были скопированы `Tolmach.dll` и его каталог. Настройки и отчёт в `BepInEx/config` можно удалить отдельно; не удаляйте конфиги других модов и общие зависимости, которые им ещё нужны.
